# 架构说明：ECS DevOps 参考架构

## 整体架构

本方案采用华为云原生服务构建DevOps实践平台，核心架构如下：

### 架构分层

```
┌─────────────────────────────────────────────────────────┐
│                    接入层                                  │
│  ┌─────────────────────────────────────────────┐  │
│  │              ELB (负载均衡)                      │  │
│  └─────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
                            │
┌─────────────────────────────────────────────────────────┐
│                    计算层                                  │
│  ┌─────────────────────────────────────────────┐  │
│  │                  CCE Cluster                    │  │
│  │  ┌──────────────────────────────────────┐  │  │
│  │  │         Backend Pod (FastAPI)         │  │  │
│  │  │         Frontend Pod (Flask)         │  │  │
│  │  └──────────────────────────────────────┘  │  │
│  └─────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
                            │
┌─────────────────────────────────────────────────────────┐
│                    数据层                                  │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐             │
│  │ RDS MySQL │  │   OBS   │  │   LTS   │             │
│  │ (数据库)  │  │ (文件)  │  │ (日志)  │             │
│  └─────────┘  └─────────┘  └─────────┘             │
└─────────────────────────────────────────────────────────┘
```

## 核心组件

### 1. CCE (Cloud Container Engine)
- 华为云Kubernetes托管服务
- 支持自动弹性伸缩
- 多可用区部署

### 2. SWR (Software Repository)
- 容器镜像仓库
- 权限管理
- 镜像加速

### 3. ELB (Elastic Load Balance)
- 流量分发
- 健康检查
- SSL卸载

### 4. RDS MySQL
- MySQL兼容数据库
- 高可用副本集
- 自动备份

### 5. LTS (Log Tank Service)
- 日志收集
- 指标监控
- 告警通知

## CI/CD 流程

### 自动化流水线

```
GitHub → GitHub Actions → SWR → CCE → LTS
  │              │            │        │
  │              │            │        │
  ▼              ▼            ▼        ▼
代码提交      镜像构建    镜像推送  自动部署  日志收集
```

### 详细步骤

1. **代码提交**：开发者推送代码到GitHub
2. **自动触发**：GitHub Actions检测到push事件
3. **构建测试**：运行单元测试和构建Docker镜像
4. **推送镜像**：镜像推送到SWR
5. **部署更新**：更新CCE中的Deployment
6. **健康检查**：验证服务可用性
7. **日志收集**：LTS自动收集日志

## 网络设计

### VPC规划
```
VPC: 10.0.0.0/16
├── 公有子网: 10.0.1.0/24 (ELB)
└── 私有子网: 10.0.2.0/24 (CCE/RDS)
```

### 安全组规则
```
入站规则:
- HTTP (80) - ELB
- HTTPS (443) - ELB
- 应用端口 (8080) - CCE Pods
- MySQL (3306) - 内部访问
- 全部TCP - VPC内互通
```

## 高可用设计

### CCE高可用
- 多可用区节点部署
- Pod副本分散在不同节点
- 健康检查与自动重启

### 数据库高可用
- 3节点副本集
- 自动故障切换
- 定期备份

### 负载均衡高可用
- 多可用区ELB
- 健康检查
- 自动摘除故障实例
